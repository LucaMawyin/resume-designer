# Resume Designer

Resume Designer is a web-based application for creating and customizing resumes through an interactive editor and generating professional LaTeX documents.

## Features

- Interactive resume editor
- Real-time resume preview
- Dynamic resume customization
- Automated LaTeX generation
- Real-time console for displaying request statuses and debugging messages
- REST API for document generation

## Tech Stack

- **TypeScript**
- **React**
- **Python**
- **Flask**
- **LaTeX**
- **Vercel**
- **AWS EC2**
- **GitHub Actions**
